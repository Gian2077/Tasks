# Test Plan - Tasks

## 1. Goal

Validate the key functionalities of the Tasks system, ensuring that task management operations work according to the defined requirements.

## 2. Scope

The following will be tested:

- Task creation
- Task editing
- Task deletion
- Task completion
- Task descriptions
- Task types
- Data persistence
- Steps management
- Rest API

## 3. Test Types

- Functional tests
- Integration tests
- API tests
- Regression tests
- Exploratory tests
- Automated tests

## 4. Environment

**Front-end:** React + Vite
**Back-end:** Java + Spring Boot
**Database:** PostgreSQL

**Tools**

- Jest
- React Testing Library
- Postman
- Git
- GitHub
